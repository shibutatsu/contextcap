# ContextCap Private — macOS

選択した1つのウィンドウを5秒間隔で記録する、ContextCapのmacOS用フォークです。macOS 14以降が対象です。Android版は変更していません。

## 起動と記録

```sh
cd macos
./scripts/build-app.sh
open 'build/ContextCap Private.app'
```

起動時は停止しています。「ウィンドウを選択」でmacOS標準ピッカーから対象を選び、「記録開始」で開始します。「一時停止」で撮影と新規保存を止めます。ロック・スリープ・セッション切替でも停止し、対象の再選択が必要になります。

ビルドはローカルのad-hoc署名です。Appleの公証済み配布版ではありません。Applicationsへコピーする場合だけ `INSTALL_APP=1 ./scripts/build-app.sh` を実行します。ログイン起動は初期状態でOFFであり、有効にしてもアプリ起動後は記録を開始しません。

## 変更点と保存仕様

- キー入力監視を削除しました。Accessibility権限を要求する処理はありません。
- 撮影対象は明示的に選んだ単一ウィンドウです。画面全体の記録はありません。
- 画像とOCR結果を同じSQLiteレコードに保存します。OCRが失敗した画像も保存しません。
- 停止・対象変更・削除によりセッションを無効化します。処理中の撮影やOCRが後から完了しても保存しません。
- 保持期間は1・3・7日、初期値は3日です。起動時・保存時・起動中の60秒間隔で、期限切れの画像と文字を同時に削除します。アプリが終了中の期限削除は次回起動時です。
- 画像と文字の合計ペイロード上限は2GBです。超過時は古い記録から削除します。SQLiteのファイルサイズ上限とは異なり、空きページが残る場合があります。
- 「すべて削除」は確認後にデータベースを作り直します。キャンセル時も記録は停止したままです。
- 外部への送信処理・外部パッケージ依存を持ちません。OCRはApple Visionを使います。

保存先は `~/Library/Application Support/ContextCap Private/archive.sqlite` です。保存ディレクトリは所有者だけがアクセスできる0700、DBは0600で作成します。バックアップ除外属性を指定します。旧版の `~/ContextCap` と `~/ContextCap-analysis` は移行・変更・削除しません。

## 制約

保存内容は暗号化していません。同じmacOSユーザー権限の別プロセスや管理者からの読み取りを防ぐものではありません。削除はアプリからの読み出しとSQLiteの現行データを対象とし、SSDの物理消去や既存バックアップからの消去を保証しません。選択したウィンドウ内に表示された秘密情報は記録対象になります。

表示するのは最新の記録とOCR結果です。過去記録の検索・一覧や旧版の解析スクリプトとの互換性は、この改修の対象外です。

## 検証

```sh
./scripts/run-tests.sh
```

Xcodeの既定ビルド方式でFile Providerの拡張属性による署名エラーが起きる環境では、`swift test --build-system native` で実行できます（Swift 6.4では非推奨オプション）。アプリのビルドスクリプトは生成したバンドルの拡張属性を署名前に除去します。

確認対象は [PRIVACY-QA.md](PRIVACY-QA.md)、実行結果は [QA-RESULTS.md](QA-RESULTS.md) に記録します。自動テストの成功と画面での動作確認は区別します。
